# EEG Hardware System

This repository contains the hardware design files for the N-Pulse EEG system.

The project is divided into three main subsystems:

- `eeg-board/` — EEG acquisition electronics
- `power-board/` — power supply, battery management, charging, and protection
- `headset/` — mechanical headset design and electrode integration

The electronic boards are designed in KiCad. Git is used for version control and collaboration between team members.
